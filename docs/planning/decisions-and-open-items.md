# 미결 선택·실험

이 문서는 아직 닫히지 않은 선택과 실험 과제만 관리한다. 확인된 제품 요구와 비목표는 [PRD](../PRD.md), 기술 구조와 불변식은 [ARCHITECTURE](../ARCHITECTURE.md)와 [BUSINESS-LOGIC](../BUSINESS-LOGIC.md), 확정된 중요한 결정과 trade-off는 [ADR](../ADR.md)이 정본이다. 검토 중인 기술안은 이 문서에 둔다.

## 사용자·운영자가 결정할 사항

| 시점 | 미결 선택 | 판단 기준 |
|---|---|---|
| 기기 연결 시 | 두 PC의 실제 설치 버전·기존 session 연결 가능 범위 | Codex/Claude와 모델·effort는 각자가 웹에서 선택하며 L1/L2/L3의 실제 지원과 전환 부담 확인 |
| 실제 공급자 검증 전 | 기존 로그인 실행의 적격성과 호출 계정·비용 | 개인 설정 유지와 기존 Claude 구독 로그인 우선은 확정; 공식 제품 조건과 설치 버전의 실제 실행 확인 |
| 회사 확장 전 | SSO·조직 계정·다른 PC의 동일 사용자 복구 | 회사 공용 코드+표시 이름으로 입장하며 이름만으로 기존 user·기기 소유권을 복구하지 않음 |
| 후속 통합 전 | Realtime 전달과 runtime 복구의 세부 계약 | HttpOnly 사람 인증·별도 기기 scope, 실제 지연·운영 한도와 권한 취소 |
| 파일럿 전 | 기본 공개 범위와 자동 전송 범위 | 필요한 최소 코드 발췌·로그·도구 이벤트 |
| 개인 설명 기능 착수 전 | 개인 설명 보관과 클라우드 처리 허용 여부 | 공용 이력과의 격리, 개인 데이터 정책; 기본 채팅의 선행 조건이 아님 |
| 파일럿 전 | 지원 OS·네트워크와 두 PC 동시 사용 조건 | 실제 사용자 기기·VPN·프록시·절전 동작 |
| 파일럿 전 | 방 재개와 오프라인 담당자 대체 권한 | 공동 정지와 재개 권한의 분리, 소유자 책임 |
| 운영 전 | 보관·삭제·백업·비용·사용 한도 | 데이터 최소화와 장애 복구의 균형 |
| 회사 확장 전 | 업무용 플랜·계정·데이터 정책 | 개인·비상업용 초기 범위와 분리된 적격성 검토 |
| 후속 | 코드 수정·커밋·PR·배포 지원 여부 | 조사 효과 확인 후 권한·검증·rollback 범위 결정 |

문서 정리 자체는 위 선택의 승인이 아니다. 이후 승인된 단계별 구현으로 채택한 언어·중앙/로컬 경계와 기기 인증, 기존 개인 에이전트 설정 유지는 [ADR](../ADR.md)에 기록했다. 각자의 웹 도구·모델·effort 선택과 상대 프로젝트 표시 요구는 확정했으며 현재 구현 상태와 남은 검증은 [AI 연동](../research/ai-runtime-integration.md)을 따른다. 실제 공급자 인증 적격성은 해당 연결 단계에서 확인한다.

2026-10-07 사용자는 사람→상대 AI 답변→같은 대화 후속 질문을 기본 사용 흐름으로 다시 확인했다. 이 흐름에는 질문자 AI·경로와 자동 공동 조사의 방향 수정이 필요하지 않다. [공식 Claude 연결 보정 기록](../impl-spec/archive/030-native-claude-chat-and-follow-up.md)은 기존 022의 승인 범위에서 로컬 실제 수용과 종료 리뷰를 마쳐 보관했다. 두 Mac의 현장 수용은 [다음 작업 순서](delivery-and-validation.md#다음-작업-순서)에 남는다. 개인 설명 저장과 자동 공동 조사 개입의 선택은 해당 후속 기능에서 확인한다.

## 검토 중인 기술 선택

첫 구현의 제품 분리·Next.js/TypeScript·Node 24·Supabase Auth/Postgres·outbound connector는 [ADR-002](../ADR.md#adr-002--첫-구현의-언어와-중앙로컬-경계)로 채택했다. 아래는 그 선택의 연구 배경과 남은 후속 통합 대안이다. 실제 Realtime·클라우드 배포·provider 실행까지 완료한 결정 기록은 아니다.

### 기존 백엔드와 분리된 제품 경계

공동 조사 제품을 조사 대상 저장소들과 별도 저장소·배포 자원으로 구성한다. 대상 서비스의 데이터와 배포 장애 영역을 분리하고 여러 도메인에 적용할 수 있지만 새 운영 단위가 생긴다. 특정 대상 서비스 안에 기능을 넣는 대안은 업무 결합과 권한 확대로 인해 현재 권고하지 않는다.

### Vercel 웹/API와 Supabase 공동 상태 사용

Vercel Hobby의 웹·짧은 제어 API와 Supabase Free의 Auth/Postgres/Realtime을 첫 후보로 사용한다. 확정 기록과 실행 상태는 Postgres, 변경 알림과 임시 표시는 Realtime이 맡는다. Vercel native WebSocket이나 별도 상시 중계 서버도 대안이지만 연결 수명·외부 조율 또는 별도 운영 부담이 있다. 무료 한도는 비용 목표이지 내구성·권한 검사를 약화하는 근거가 아니며, 플랜을 자동 유료 전환하지 않는다.

### 로컬 outbound connector가 AI 실행을 소유

각 PC의 connector가 등록한 저장소와 AI 세션을 소유하고 중앙 서비스로 outbound 연결한다. 공개 인바운드 포트나 원격 셸을 두지 않으며 공급자 인증과 절대 경로는 로컬에 남긴다. 실행 관찰·중단을 구조화할 수 있는 대신 기존 앱 경험과 맥락 이전 비용이 생긴다. 실행 중인 타 앱 세션 연결(L3)은 보장하지 않고 실험하며, 실패하면 선택 맥락이나 저장 세션(L1/L2)을 명시적으로 사용한다.

### 명령 한 번으로 로컬 연결 실행

2026-10-07 사용자는 기존 Claude/Codex를 유지하고 별도 앱 설치·프로젝트 복제 없이 웹의 명령 한 번으로 연결 코드를 임시 실행하는 방식을 허용했다. [PRD](../PRD.md#로컬-ai-연결)와 [031 계획](../impl-spec/archive/031-one-command-local-connection.md)에 반영했다. 현재 실행·권한·복구 모듈을 재사용하고 운영 코드만 임시 배포한다. Node가 없는 Mac도 공식 고정 배포본을 검증해 임시 실행한다.

원격 MCP의 지원은 확인했으나 웹 모델·effort·중단과 실제 읽기 권한을 포함한 실행기의 대체로 채택하지 않는다. Channels는 로컬 코드와 허용 목록 조건이 있고 Remote Control은 자기 계정의 공식 화면용이다. [비교 근거](../research/local-ai-connection-research.md#별도-연결-프로그램-설치를-없애는-대안)를 따른다. 임시 연결 프로세스의 실행은 남는다. 새 배포·진입은 독립 검토를 마친031의 계속 진행 범위다. 사용자의 계속 진행 지시로 같은 채팅 연결 구현을 이어갔으며 현재 검증과 실제 Claude·두 PC 수용은 [다음 작업 순서](delivery-and-validation.md#다음-작업-순서)에 별도로 남긴다.

### 내구 상태와 실시간 표시를 분리

확정 메시지·요청·revision·권한·개입은 DB에, 작성 중 표시·presence·변경 알림은 Realtime에, runtime 호출 경계와 업로드 대기는 로컬 저널에 둔다. 실시간 채널만 사용하는 대안은 누락·중복·재접속과 호출 직후 장애를 복구하기 어렵다. 이 선택은 exactly-once를 약속하지 않으며 UNKNOWN 상태, idempotency key, lease/fence, `roomRevision`, `bindingEpoch`를 분리해 늦거나 오래된 결과의 자동 채택을 막는다.

### 첫 버전은 조사·제안 범위로 제한

첫 버전은 읽기, 허용된 격리 테스트, 수정 제안까지만 지원하고 파일 수정·커밋·배포 자동화와 원격 셸은 비목표로 둔다. 사용자가 개인 설정 유지에 관한 후속 질문에서도 이 범위를 확정했다. 개인 설정이 쓰기를 허용해도 공동 조사 작업의 수정 권한으로 확대하지 않는다. 후속 선택은 읽기 전용 우선이며 권한을 검증하지 못한 MCP·플러그인·훅 실행은 조사 동안 제한한다. 개인 지침·설정 파일은 유지하며 실행 상한만 작업에 적용한다. 자동 실행까지 넓히는 대안은 시연 범위는 커지지만 권한·승인·rollback 검증이 제품 가치 검증보다 먼저 필요해진다. 현재 제품 범위와 비목표의 정본은 [PRD](../PRD.md#non-goals)다.
